## Tabelas do Banco de Dados

### `npc_reputation`
```sql
CREATE TABLE npc_reputation (
    user_id BIGINT,
    npc_id VARCHAR(50),
    reputation INT DEFAULT 0,
    title VARCHAR(100),
    total_purchases INT,
    total_gold_spent BIGINT,
    last_interaction TIMESTAMP,
    PRIMARY KEY (user_id, npc_id)
);
```

### `traveling_merchant`
```sql
CREATE TABLE traveling_merchant (
    spawn_id SERIAL PRIMARY KEY,
    zone_id BIGINT,
    spawned_at TIMESTAMP,
    despawn_at TIMESTAMP,
    is_active BOOLEAN,
    visitors_count INT
);
```

### `traveling_merchant_inventory`
```sql
CREATE TABLE traveling_merchant_inventory (
    spawn_id INT,
    item_id INT,
    tier INT,
    price BIGINT,
    quantity INT,
    is_sold BOOLEAN,
    PRIMARY KEY (spawn_id, item_id, tier)
);
```

### `npc_dialogues`
```sql
CREATE TABLE npc_dialogues (
    dialogue_id SERIAL PRIMARY KEY,
    user_id BIGINT,
    npc_id VARCHAR(50),
    dialogue_type VARCHAR(50),
    message TEXT,
    created_at TIMESTAMP
);
```

### `npc_daily_quests`
```sql
CREATE TABLE npc_daily_quests (
    quest_id SERIAL PRIMARY KEY,
    npc_id VARCHAR(50),
    user_id BIGINT,
    quest_type VARCHAR(50),
    target_id INT,
    target_amount INT,
    current_progress INT,
    reward_reputation INT,
    reward_gold BIGINT,
    completed BOOLEAN,
    claimed BOOLEAN
);
```

## Dicas e Estratégias

### Maximizando Reputação
1. **Foque em um NPC:** Chegue a 5000 pontos com um antes de diversificar
2. **Compre frequentemente:** Mesmo itens baratos dão reputação
3. **Complete missões diárias:** Maior fonte de reputação
4. **Interaja sempre:** Use `/talk` regularmente

### Caçando o Mercador Viajante
1. **Use `/merchant` frequentemente:** A cada 15 minutos
2. **Fique em hubs populares:** Mais chance de ser notificado
3. **Tenha ouro guardado:** Itens lendários custam 300k-1M gold
4. **Construa reputação com ele:** 1000 pontos = ele te avisa quando aparece!

### Ordem Recomendada de NPCs
1. **Martha (Estalajadeira):** Buffs úteis para level
2. **Gorak (Ferreiro):** Equipamentos melhores
3. **Lysandra (Mercadora):** Lucro em vendas
4. **Thaddeus (Alquimista):** Poções poderosas
5. **Morgath (Encantador):** Bônus permanentes
6. **Raven (Mercado Negro):** Para aventureiros avançados
