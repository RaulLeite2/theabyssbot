════════════════════════════════════════════════════════
                  GUIA DE USO RÁPIDO
════════════════════════════════════════════════════════

🚀 MÉTODO RÁPIDO (RECOMENDADO):
1. Crie TODOS os itens com /genitem (copie e cole do topo do arquivo)
2. Use /getitem para verificar o ID do PRIMEIRO tier de cada item
3. Use /addcraft APENAS no primeiro tier (exemplo: Espada de Ferro T2.0)
4. Quando perguntado, escolha "🔥 Criar Para Todos os Tiers"
5. Pronto! Todas as receitas T2.0 até T3.4 serão criadas automaticamente

📋 EXEMPLO PRÁTICO:
Você criou "Espada de Ferro" de T2.0 até T3.4 (10 tiers)
ID do T2.0 = 21

Comando:
/addcraft item_id:21 madeira:40 minerio:50 pedra:20

Bot pergunta: "Criar para todos os 10 tiers?"
Você clica: "🔥 Criar Para Todos os Tiers"

Resultado:
✅ T2.0: 40 madeira, 50 minério, 20 pedra
✅ T2.1: 44 madeira, 55 minério, 22 pedra
✅ T2.2: 48 madeira, 60 minério, 24 pedra
... (até T3.4 automaticamente escalonado)

⏱️ Economize tempo: 1 comando ao invés de 10!

                      NOTAS IMPORTANTES
════════════════════════════════════════════════════════

1. ⚠️ Os IDs acima são EXEMPLOS! Use /getitem para verificar os IDs reais

2. 🪵 Recursos disponíveis:
   • Madeira - Estruturas, arcos, cajados
   • Pedra - Base, fortalecimento
   • Minério - Armas, armaduras metálicas
   • Fibra - Tecidos, roupas leves
   • Pelego - Couro, proteção
   • Cristal - Encantamentos e itens raros
   • Ervas - Poções e consumíveis

3. 🔢 Custos escalam automaticamente:
   T1.0 → T2.0 = 2x mais caro
   T1.0 → T3.0 = 3x mais caro
   T1.0 → T8.0 = 8x mais caro

4. 📦 Jogadores coletam recursos com /explore

5. 🔨 Comandos de crafting:
   • /craft - Interface interativa
   • /recipes - Ver todas as receitas
   • /myresources - Ver recursos disponíveis

6. 🎯 DICA DE ADMIN: 
   • Crie PRIMEIRO os recursos coletáveis (slot_id:9, is_collectible:true)
   • Depois crie os itens T1.0 de cada tipo
   • Por fim crie os T2.0, T4.0 e T6.0
   • Isso facilita encontrar os IDs!

7. ✨ NOVO: Confirmação antes de criar itens
   • O comando /genitem agora mostra uma prévia do que será criado
   • Confirme com ✅ ou cancele com ❌
   • Útil para evitar criações acidentais

8. 🌿 Recursos coletáveis:
   • Use is_collectible:true ao criar recursos
   • Recursos aparecem no comando /explore
   • Slot ID 9 é reservado para recursos (não equipáveis)
